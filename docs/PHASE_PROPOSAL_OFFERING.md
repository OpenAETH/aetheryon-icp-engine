# Phase · Propuesta / Offering Definition

The Offering entity now follows the commercial catalog structure instead of a generic name/outcome form.

## Canonical fields

1. Línea
2. Producto / Servicio
3. Propósito
4. Dinámica
5. Resultado
6. Cotización
7. Notes
8. Pains que resuelve

The database stores the commercial fields separately so they remain queryable and reusable by ICP/Search definitions.

The existing Pain relationship through `pain_offerings` is preserved.
